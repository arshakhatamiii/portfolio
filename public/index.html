    E-Commerce Platform & Admin Suite

    GitHub ↗
    Problem
    An online store needs to stay fast under traffic spikes while giving the owner a simple way to manage products, orders and customers.
    Decision
    ASP.NET Core Web API on PostgreSQL with EF Core migrations applied automatically on deploy. Redis cache-aside for hot reads such as the product catalog, and a custom admin dashboard built on the same API. Everything runs in Docker for identical dev and prod environments.
    Result
    Deploys went from manual to fully automated. Every flow in the admin panel, down to the smallest button, is covered by Playwright end-to-end tests.
    .NET PostgreSQL Redis Docker Playwright

    Multi-Stage CI/CD & Edge Security Pipeline

    GitHub ↗
    Problem
    Manual deployments were slow and error-prone, and the public API was exposed to abusive traffic with no layered protection.
    Decision
    GitHub Actions pipeline with separate build, test, security-scan and deploy stages that ships versioned Docker images. Nginx as a hardened reverse proxy with rate limiting, behind Cloudflare WAF, on a locked-down Linux host.
    Result
    Fully automated deploys with no manual steps between merge and production, and abusive requests filtered at the edge before they reach the API.
    GitHub Actions Nginx Cloudflare Linux
